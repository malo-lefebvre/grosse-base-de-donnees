# Progression de révision

Cette branche ne contient que des données chiffrées avec le mot de passe du dashboard :

- `etat.bin` : ta progression (boîtes de Leitner, cartes modifiées, réglages), écrite par la page Révision ;
- `envois.bin` : les résumés et notes de connexion à écrire dans Notion, appliqués par le workflow
  « Appliquer les envois de révision » (le code est sur `main`, dans `sync/apply.py`).

Ne la fusionne pas dans `main`.
